┌─────────────────────────────────────────────────────────────────────────────┐
│  🌐 CUSTOM DOMAIN SETUP (5 MINUTES)                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. Azure Portal → Your Static Web App → Custom domains → Add               │
│                                                                              │
│  2. Add DNS Record (at your domain registrar):                               │
│     Type: CNAME                                                              │
│     Name: www                                                                │
│     Value: [your-app].azurestaticapps.net                                   │
│     TTL: 3600                                                                │
│                                                                              │
│  3. Wait 5-10 minutes for:                                                   │
│     • DNS propagation                                                        │
│     • SSL certificate provisioning                                           │
│                                                                              │
│  4. Done! Visit https://www.nebulax.com ✅                                  │
│                                                                              │
│  Popular Registrars:                                                         │
│  • GoDaddy: DNS Management → Add Record → CNAME                             │
│  • Namecheap: Advanced DNS → Add New Record → CNAME Record                  │
│  • Cloudflare: DNS → Add record → CNAME (grey cloud)                        │
│                                                                              │

┌─────────────────────────────────────────────────────────────────────────────┐
│  🛠️ TROUBLESHOOTING                                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Problem: Build fails                                                        │
│  → Check GitHub Actions logs for errors                                      │
│  → Verify output_location is "build"                                         │
│  → Test build locally: npm run build                                         │
│                                                                              │
│  Problem: Environment variables not working                                  │
│  → Must start with REACT_APP_                                                │
│  → Set in Azure Portal → Configuration                                       │
│  → Redeploy after changing (automatic)                                       │
│                                                                              │
│  Problem: Custom domain not working                                          │
│  → Wait 5-10 minutes for DNS propagation                                     │
│  → Verify CNAME in DNS registrar                                             │
│  → Check Azure Portal → Custom domains → Status                              │
│                                                                              │
│  Problem: API not responding                                                 │
│  → Check api_location in workflow config                                     │
│  → Verify function.json exists                                               │
│  → Check Azure Portal → Functions → Logs                                     │
│                                                                              │
│  Problem: Slower than expected                                               │
│  → CDN needs time to propagate (first deploy)                                │
│  → Check Application Insights for metrics                                    │
│  → Optimize assets (images, code splitting)                                  │
