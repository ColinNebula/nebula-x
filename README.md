##  Quick Start

### Play Online
Visit **[https://colinnebula.github.io/nebula-x/](https://colinnebula.github.io/nebula-x/)** to play instantly in your browser!

### Run Locally
```bash
npm install
npm start
```
Game launches at `http://localhost:5173`
